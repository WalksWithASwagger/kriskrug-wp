# Monthly measurement readout

Blank template for the read-only monthly readout on [kriskrug.co](https://kriskrug.co/), first due December 1, 2026. Copy it to `docs/current-state/reports/monthly-readout-<YYYY-MM>.md` and fill it. Keep this file as the blank source.

Owner issue: #1279. This is a measurement record, not a publish, send or outreach step. Do not edit live WordPress, Beehiiv or Search Console from it.

## How to use

1. Copy the template on the 1st of the month and set the dates below.
2. Fill every row from its stated source, or write "not measured" and say why in the "Not measured because" column. A blank cell is not allowed.
3. Subscriber and inquiry numbers appear in the public repo only if Kris approves them. Until he does, report direction only (up, flat, down) and keep counts private.
4. Use the signed-in browser for Search Console only if Kris has granted that access. Otherwise mark the row "not measured".
5. No credentials, no personal data, no individual email addresses or names.
