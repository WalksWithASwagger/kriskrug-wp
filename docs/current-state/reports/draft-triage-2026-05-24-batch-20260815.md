## 2. My audit was too harsh, and here is the evidence

KK sampled four packages and generalized. The sample was accurate about those four and wrong about
the batch. `2026-05-24-*` is **not one batch. It is two populations that share a folder date**, and
the file manifest tells them apart before you read a word:

**Population A: the curated line (6 packages).** Manifest has 7 to 8 files including
`publish-gate.md` and `image-brief.md` or `ASSETS.md`. Frontmatter has **no** `notion_source`.
Category is a real one (`AI Ethics & Philosophy`, `Vancouver AI Ecosystem`, `AI for Creatives`).
Body ends in a `## Related` block with working links. Zero stray HTML entities. These are real KK
posts. Five are live. The sixth is withdrawn by KK ruling.

**Population B: the archive import (22 packages).** Manifest is exactly five files
(`alt-text.md`, `internal-links.md`, `post.html`, `post.md`, `seo-meta.md`), one exception with an
empty `images/` dir. Frontmatter carries a `notion_source` page ID. Category is `Misc`. Zero images,
zero internal links, no Related block. `alt-text.md` literally reads "(no images)" and
`internal-links.md` reads "## Internal links (0)". These are the slop.

So the honest headline is: **22 of 28 are the problem, not 28 of 28. Six were never slop.**

Two more corrections to the audit's specifics:

- **Word count range was wrong.** The audit said "404 to 1,535 words." Body-only counts across the
  22 archive packages run **220 to 5,221**. The largest file in the batch
  (`keynote-music-elevation-series-haus-of-owl`, 5,221 words) is also the least publishable.
  Length is not the signal here.
- **The `{EMDASH}` count is zero across all 28 payloads.** The batch does not fail the em dash rule.
  It fails the rule that replaced it. `docs`-side the remediation README is explicit: "No hyphens,
  no en dashes, no spaced hyphens standing in for the old dash." The import converted every dash to
  a bare hyphen, producing constructions like `answers-hell, I'm probably more confused than most`
  and `There you have it-a friendly, witty critique`. That reads worse than the original dash and
  a naive `{EMDASH}` grep will never catch it.
- **A verifiable import defect the audit missed:** 15 of the 22 archive packages carry raw
  undecoded HTML entities (`&#x27;`, `&quot;`, `&amp;`) in the markdown body. Counts:
  `keynote-music-elevation` 309, `guide-to-hacking-language` 124, `outline-for-droid-army` 90,
  `finding-harmony` 60, `transmuting-words` 50, `human-element` 43, `nik-badminton` 30,
  `the-synthetic-renaissance` 28, `why-100-young-canadians` 18. All six Population A packages read
  zero. This is a clean machine-checkable discriminator if you ever need to re-sort the queue.
