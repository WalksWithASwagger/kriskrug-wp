## Method

Resolution order mirrors `scripts/events_page/fetch_event_heroes.py` and the #587 engine
contract:

1. KK's own archive or an asset already sitting in the kriskrug.co media library
2. Event organizer's public press or event page
3. Public event listing (Luma, Eventbrite, conference site)
4. Rafiki generation, only where no public asset exists, and always flagged as generated

Sources actually swept for this pass:

- `scripts/events_page/fragments/one-offs-2024.yaml` and `one-offs-2025.yaml` (the
  `hero_hint` strings that seeded this work)
- kk-kb appearance records and page snapshots under
  `content/projects/05-marketing-and-outreach/press-and-media/appearances/`
- kk-kb image tree (`media/`, `content/media/`, per-project `assets/images/`)
- Public unauthenticated GETs against kriskrug.co, kriskrug.beehiiv.com, luma.com,
  lu.ma, images.lumacdn.com, vancouver.websummit.com, damavancouverbcchapter.wildapricot.org,
  visionconference.ca, and the Yorkton Film Festival asset host
- Public web search for the two rows with no on-file pointer

### Hard limits on this pass

- **No image binary was downloaded and no image was opened.** Every proposed alt text is
  derived from filename, source page copy, and asset role, not from looking at the frame.
  Treat all alt text as a draft the ship agent confirms against the actual image at upload.
- **No WordPress API calls.** The `wp-image-NNNN` media IDs quoted below were read out of
  the public post HTML on kriskrug.co, not from an authenticated media query. Confirm each
  ID before attaching it.
- **No one was contacted.** Every permission gap stays a gap.

### HTTP verification

Every candidate URL in this ledger was checked with `curl` on 2026-08-02. `200` means a
full GET returned image bytes. `206` means a byte-range GET returned image bytes, which is
the same success signal, just a partial fetch so no large binary landed on disk. Any URL
not listed here was not checked and must not be treated as verified.

### Rights basis vocabulary

| Value | Means |
|---|---|
| `KK own asset` | KK or a KK-run org created or already published the asset. Safe to upload. |
| `KK own asset, third-party art risk` | The asset lives on a KK-controlled surface, but the artwork inside it probably originates with someone else. Needs a look before publishing. |
| `organizer art, no license found` | Real asset, real source, but no public license or press-kit terms. Not safe to upload. |
| `none found` | No defensible source exists yet. |
